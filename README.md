# Chess Review

Live app: https://rolandnaidoo22-hash.github.io/chess-review/

A single-page chess game reviewer: paste a Chess.com PGN (or load your latest games) and it analyses the game
in your browser with Stockfish (WebAssembly), grades every move with standard symbols (!!, !, ?!, ?, ??), explains mistakes, shows
practice lines and the BAD check. Works offline and can be installed with "Add to Home screen".

`index.html` is generated by `review.py` in the source folder. Stockfish is GPLv3 (stockfish.js by Nathan Rugg / Chess.com);
chess.js is BSD-2; the opening names come from lichess-org/chess-openings (CC0).
